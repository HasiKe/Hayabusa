# Hayabusa Gen 1 Sitzneubezug - Projektübersicht

## Projektinfo
- **Motorrad:** Suzuki Hayabusa GSX1300R (1. Generation, 1999-2007)
- **Projekt:** Komplette Sitzneubezugung
- **Stil:** Sportlich-Elegant mit Alcantara-Akzenten

## Fahrzeug-Spezifikationen (Gen 1 Hayabusa)
| Spezifikation | Wert |
|--------------|------|
| Gesamtlänge | 2180 mm |
| Gesamtbreite | 740 mm |
| Sitzhöhe | 805 mm |
| Radstand | 1485 mm |
| Leergewicht | 215 kg |

## Ziele
1. ✅ Moderner, sportlicher Look
2. ✅ Verbesserte Sitzkomfort durch hochwertiges Material
3. ✅ Alcantara-Design-Elemente für Premium-Feeling
4. ✅ UV-beständige und wetterfeste Materialien

## Zeitplan (geschätzt)
| Schritt | Geschätzte Zeit |
|---------|----------------|
| Demontage Sitz | 30 Min |
| Alten Bezug entfernen | 1-2 Std |
| Schaum anpassen (optional) | 1 Std |
| Neubezug vorbereiten | 1 Std |
| Bezug anbringen | 3-4 Std |
| Montage | 30 Min |
| **Gesamt** | **~8-10 Std** |

## Werkzeug-Checkliste
- [ ] Schraubendreher/Torx-Satz
- [ ] Zange (für Klammern)
- [ ] Klammerentferner oder Schraubenzieher
- [ ] Scharfe Schere
- [ ] Nadel und Nähgarn (Nylon/Polyester)
- [ ] Sprühkleber (3M 77 oder ähnlich)
- [ ] Heißklebepistole (optional)
- [ ] Lineal/Maßband
- [ ] Stoffkreide/Marker

## Tipps & Hinweise
- **Temperatur:** Bei kaltem Wetter das Vinyl vor Verarbeitung bei Raumtemperatur lagern
- **Spannung:** Material gleichmäßig spannen - keine Falten, aber auch nicht zu straff
- **Nähte:** Doppelnaht für kritische Bereiche empfohlen
- **Trockenzeit:** Kleber vollständig tacky werden lassen vor dem Andrücken

## Kamera-Setup pro Szene

### Szene 1: Intro
- **Hauptcam:** Medium, 45°, Augenhöhe
- **Licht:** Key + Fill, Rim optional
- **Audio:** Lav + Shotgun als Backup

### Szene 2: Build/Arbeit
- **Hauptcam:** Wide fix auf Stativ
- **Zweitcam:** Handheld/Detail
- **GoPro:** POV oder Overhead
- **Audio:** Lav (wenn möglich), sonst Voiceover später

### Szene 3: Detail/Macro
- **Hauptcam:** Macro-Objektiv, statisch
- **Licht:** Ringlight oder kleines LED-Panel
- **Audio:** Voiceover oder ASMR-Style

---

## Audio-Checkliste

- [ ] Lav-Mic getestet, keine Kabelbrüche
- [ ] Shotgun positioniert, keine Reflexionen
- [ ] Zoom H6 als Backup läuft
- [ ] Voiceover-Mic bereit (ruhiger Raum)
- [ ] Werkstattlärm gemessen (Kompressor, Schleifer)
- [ ] Dead Cat drauf (Windschutz)

---

## Licht-Checkliste

- [ ] Key-Light positioniert (45° seitlich, 45° oben)
- [ ] Fill-Light gesetzt (weich, gegenüber)
- [ ] Rim-Light optional (von hinten)
- [ ] Decken-LEDs an (Grundhelligkeit)
- [ ] Practicals im Bild (Atmosphäre)
- [ ] Weißabgleich gesetzt (5500 K oder 3200 K)
- [ ] Kein gemischtes Licht (Tageslicht + Kunstlicht)
